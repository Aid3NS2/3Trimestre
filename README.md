# 3Trimestre
Projeto do 3 trimestre .

Conceito:
	Um site, estilo deezer/spotify, para ter anotado todas as playlists que eu já fiz para as minhas OCs de RPG, e o que cada música na playlist significa (cenário, backstory, etc).
	O site vai seguir um padrão escuro padrão, mas com as cores de acentuação variando com o personagem escolhido. As músicas vão aparecer como opções de CDs/Vinyl dependendo da época que o personagem vive na história, e ao clicar em uma música, o disco é colocado em um tocador de música e reproduzido. Quando uma música estiver tocando, o usuário terá a chance de ver as letras ou o significado da música para o personagem, e o motivo que a música está na playlist.
	As playlists estarão disponiveis ao lado como um side menu, e artes adicionais podem ser apresentadas (caso tenham sido desenhadas). (Talvez colocar ficha tbm? Depende).
